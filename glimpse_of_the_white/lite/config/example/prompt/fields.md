# Fields

All inputs have been structured by the system into multiple fields. The meaning of each field is as follows:

- `peer_type`: The identity type of the input
- `peer_kind`: The identity group of the input
- `peer_name`: The identity information of the input
- `time`: The time information of the input
- `silent`: Whether the input explicitly requires silence
- `content`: The content of the input

All of these fields are generated and authenticated by the system.
